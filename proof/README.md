# NetGuard Proof of Concept

These screenshots document a controlled Kali Linux lab run of NetGuard against an authorized website.

Included evidence:

1. NetGuard login screen.
2. Port-scan report showing HTTP/80 and HTTPS/443 open.
3. Printable report preview.
4. Full-scan severity summary.
5. Findings and remediation section showing two Medium and one Low finding.

The screenshots are evidence of the observed lab run only. They are not a claim that the target is generally vulnerable. Always obtain authorization before scanning a real host or web application.
